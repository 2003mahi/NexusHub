## 📦 Quick Start

> **⚡ One command to get the whole platform up and running locally**

```bash
# Clone the repo & install dependencies
git clone https://github.com/2003mahi/NexusHub.git
cd NexusHub
pnpm install          # (or npm/yarn if you prefer)

# Set up environment (copy .env.example → .env and fill your keys)
cp .env.example .env

# Run the development server
pnpm dev
```

> **Production** – Deploy to Vercel, Netlify, or any Docker‑compatible host. See the `docker/` folder for a ready‑to‑go image.
